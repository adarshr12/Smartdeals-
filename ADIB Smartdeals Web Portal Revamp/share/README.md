# ADIB Smartdeals – Web Portal Revamp

- `index.html` – design board with every screen, state and annotation (live, scroll horizontally on wide sections).
- `ADIB Smartdeals Prototype.html` – clickable prototype (Home → All offers grid/map → Offer detail → redeem). Linked from the board's "Open clickable prototype" button.

Both files are self-contained (images inlined). An internet connection is needed for fonts, icons and the live map tiles.

GitHub Pages: push this folder to a repo, enable Pages on the branch root, open `/` for the board or `/ADIB%20Smartdeals%20Prototype.html` for the prototype.

All merchant values are sample data; merchant photos are cropped from the current ae.adibsmartdeals.com for illustration.
